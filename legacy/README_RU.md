# Исходная программа aero2d

Сохранены две исходные версии из пользовательских архивов: первоначальная
и от 25 октября 2026 года. Они не являются текущим AeroKinetic и не
используются как экспериментальный эталон. Источники/README каждой версии
сохранены для истории и адаптера. Текущий пакет находится в ../../src/.
