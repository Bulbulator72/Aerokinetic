# Первичные файлы NASA/TMR

Скачаны 26 октября 2026 г. Оригинальные байты, размеры, URL и SHA-256
записаны в [PROVENANCE.json](PROVENANCE.json). Новые CFD-сравнения с этими
данными не выполнены. Правила использования и источник каждой таблицы
сохраняют силу; эти материалы не перелицензируются как исходный код.

| Файл | Содержимое и ограничения |
|---|---|
| CLCD_Ladson_expdata.dat | NACA0012, Re=6 млн, M=0.15, фиксированный переход, несколько grit-серий |
| CP_Gregory_expdata.dat | NACA0012, Re=2.88 млн по заголовку, верхняя поверхность, приблизительная оцифровка |
| CP_Ladson.dat | Отдельные серии Cp Ladson; условия каждой серии сверять с заголовками и первоисточником |
| n0012points_superbig_clust_fix.dat | Специальная геометрия NACA0012 TMR, три колонки x,y,z с z=0 и заголовком Tecplot |
| naca4412.cp.expt.dat | Cp случая отрыва NACA4412, с оговорками NASA/TMR о нормировке |
| naca4412.exp.profiles.new.dat | Шесть интерполированных линий x,y,u,v,uv; нестандартная Uref, добавленные точки на стенке |
| NASA_TM4074_Ladson_1988.pdf | Полный NASA TM-4074, 97 страниц; содержит Cl/Cd/Cm, таблицы ещё не извлечены целиком |
| Ladson_TM4074_table_IX_Re5p95m_80W.csv | Нижний блок таблицы IX, Re=5.95 млн, M=0.15, 80-W; 17 строк Cl/Cd/Cm(c/4), проверены визуально |

[Происхождение извлечённой таблицы](Ladson_TM4074_table_IX_Re5p95m_80W.provenance.json).
Таблица TMR округляет Re этой серии до 6 млн и использует название `80 grit`.
В PDF при α=8.30° Cl=0.8872, а в TMR — 0.8873; оригинал TMR не менялся.
Производный CSV следует PDF. Сравнение присланного расчёта Claude —
в [отчёте](../../benchmarks/claude_sa_2026-10-26/REPORT_RU.md).
Сверка нового кинетического решателя с этими данными не выполнена.

Страницы условий:

- https://tmbwg.github.io/turbmodels/naca0012_val.html
- https://tmbwg.github.io/turbmodels/naca4412sep_val.html
- https://ntrs.nasa.gov/citations/19880019495

Нужно сохранять отдельные зоны и экспериментальные определения. Заголовки
и строки `zone` не являются числовыми строками. Смешение Reynolds, Mach,
grit, верхней/нижней поверхности или нормировки скорости разрушает смысл
сравнения. Подробности — [план проверки](../../docs/BENCHMARK_PLAN_RU.md).
