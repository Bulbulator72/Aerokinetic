AEROKINETIC 0.2 — ЧТО СДЕЛАТЬ ДО ВОЗВРАЩЕНИЯ НА РАБОЧИЙ КОМПЬЮТЕР

Инструкция самостоятельной программы: START_DESKTOP_RU.md.
После установки окно запускается через 6_run_AEROKINETIC.bat.

1. Прочитайте README_RU.md. Это исследовательская версия: точность Cl/Cd/Cm
   по продувкам пока не подтверждена; для точной практической 3D задачи
   потребуется значительно большее разрешение и локальное сгущение сетки.

2. Архив windows_kit уже содержит Python-пакеты для CPython 3.12 x64 Windows
   в downloads\wheels_windows. Они проверены по версиям и SHA-256.
   В маленьком архиве source этих сторонних пакетов нет.

3. Дома с интернетом запустите 1_download_ONLINE_WINDOWS.bat: он подготовит
   пакеты при необходимости и скачает установщик Python 3.12 x64.
   Если у вас на рабочем компьютере нет компилятора Visual Studio C++,
   обязательно запустите также 1b_download_COMPILER_ONLINE.bat.
   Полный автономный C++ layout займёт несколько гигабайт. Python и C++
   установщики в исходный архив не включены.

4. Перенесите ВСЮ папку вместе с downloads. На рабочем компьютере установите
   Python и компилятор соответствующими OFFLINE BAT, если они отсутствуют.
   Затем 3_install_WINDOWS_OFFLINE.bat и 4_run_PREVIEW.bat.

5. Для разработчика: src\aerokinetic, examples\integrate_aero2d.py.
   Эталон: references\ohtake2007.pdf и оцифрованный Cl при Re=30000.
   Демо GIF: demo_wake\omega_z.gif. Демо не является расчётной полярой.
   Проверки и ограничения: VALIDATION_RU.md.

6. Расширения ChatGPT (Scite, Firecrawl) полезны для дальнейшего научного
   поиска, но библиотека не зависит от них и не обращается к интернету.
