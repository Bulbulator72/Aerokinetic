# AeroKinetic

Исследовательская программа для нестационарного трёхмерного обтекания
неподвижных многоэлементных сечений методом решёточного Больцмана.
Текущая версия — **0.5.0**: D3Q27, кумулянтный оператор, стенки Bouzidi,
равномерная и двухуровневая сетки, CPU OpenMP и настольный интерфейс.

**Физическая точность пока не подтверждена.** Рабочие ограничения
выпущенного ядра: Re=10 000...100 000, физический M<=0.15. Требуемый режим
Re около 6 млн пока не реализован. Последнее сравнение NACA0012 с
продувкой выявило существенные расхождения Cl/Cd/Cm.

## Запуск и Windows

Инструкция настольной программы: [START_DESKTOP_RU.md](START_DESKTOP_RU.md).
Переносимая сборка для офлайн-ПК: [docs/BUILD_PORTABLE_RU.md](docs/BUILD_PORTABLE_RU.md).
Последний выданный сценарий и wheel: [distribution/](distribution/).
Для Windows без интернета переносится вся папка собранной программы.

Для разработки нужен Python 3.12, зависимости из
`requirements-offline-py312.txt` и локальный C++ toolchain для JIT-компиляции.
После подготовки зависимостей:

```text
python -m pip install -e .
python -m aerokinetic.gui
```

Для автономной установки сначала подготовьте пакеты на компьютере с
интернетом по инструкции; один исходный Git-репозиторий не содержит
установленных зависимостей и Windows-компилятора.
