# Выполненные проверки версии 0.1.0

Проверка механизации в установленной **0.5.0** от 2 ноября 2026 г.:
[однощелевой, двухщелевой и Fowler](docs/verification_multielement_050/REPORT_RU.md).
Она подтверждает работу функций на Re=10000; Re≈6 млн и точность нагрузок
по продувкам этим прогоном не подтверждены. Исторический отчёт ниже сохранён.

Новые проверки сеткопостроителя, невязок/условий окончания и многопоточного
CPU версии 0.4 сохранены в [отдельном отчёте](docs/verification_040/REPORT_RU.md).
Они не меняют исторический статус аэродинамической валидации ниже.

Это исторический отчёт. Новые проверки окна, CPU-продолжения и автономной
установки версии 0.2 описаны в [RELEASE_02_RU.md](docs/RELEASE_02_RU.md).
Они не являются подтверждением аэродинамической точности по продувкам.
Проверки анализа временной истории и автономного обновления 0.2.1 сохранены
отдельно в [отчёте 0.2.1](docs/RELEASE_021_RU.md) и
[машинном журнале](docs/verification_021/CHECKS.json).

Более поздние исследовательские этапы сгущения описаны отдельно:
[разовый перенос между уровнями](docs/REFINEMENT_RU.md) и
[пространственный жидкостный стык](docs/INTERFACE_RU.md).
Версия 0.3.0 подключает профиль, нагрузки, открытые границы и продолжение:
[отчёт третьего этапа](docs/verification_refined_airfoil/REPORT_RU.md).
Они не меняют исторические результаты ниже и ещё не являются
многоуровневым расчётом профиля с подтверждёнными Cl/Cd/Cm.

Дата: 23 октября 2026 г. Платформа проверки: Linux x86_64, CPython 3.12,
CPU, double precision. Библиотека устанавливалась в отдельное чистое venv
из подготовленных wheel-файлов с `pip --no-index`. `pip check` — без
нарушенных зависимостей. Тестировался установленный wheel, не только исходники:

```text
python -m pytest -q -o pythonpath=
10 passed in 23.18s
```

Проверки включают геометрическое положение стенки на связях сетки,
отбраковку пересекающихся контуров, сохранение общей системы координат
элементов, определение Re по полной хорде, размерный шаг времени, отбраковку
неподходящего физического Ma и предварительную оценку памяти.

Для вычислительного ядра выполнен тест затухания периодической сдвиговой
волны: ν=0.03 в решёточных единицах, длина волны 32 ячейки, 120 шагов,
амплитуда 10⁻⁴. Проверка амплитуды по точному экспоненциальному затуханию
проходит с допуском 1.2%; плотность сохраняется с допуском 2·10⁻¹²,
средний импульс — 10⁻¹³. Это тест оператора вязкости, а не продувка профиля.

Для стенок проверены точное пересечение полигонального контура и связей,
нулевая сила и момент от равномерного изотропного давления на замкнутом теле,
симметрия Cl/Cm и положительный стартовый Cd симметричного NACA0012 при α=0.
Также пройден трёхмерный расчёт двух элементов с включённой моделью
Smagorinsky, сохранением кадров и конечными коэффициентами.

Прямой адаптер прочитал из предоставленного проекта aero2d: NACA0012,
однощелевой закрылок и сборку из четырёх элементов (предкрылок, основная часть,
дефлектор, закрылок). Это проверка совместимости геометрии, не валидация
нагрузок на такую механизацию.

Подготовка зависимостей реально выполнена для CPython 3.12 x64 Windows и
Linux: 26 закреплённых сторонних пакетов и wheel самой библиотеки.
Создаются SHA-256 манифесты. Windows/MSVC и GPU на реальной целевой машине
здесь не проверялись. Пакет для Windows требует локального компилятора C++.
Для него предусмотрены BAT загрузки layout и установки без сети.

Сохранён трёхмерный демонстрационный прогон: Re=10000, α=8°, 32 ячейки на
хорду, периодический размах 0.5c, SGS Smagorinsky, t*=0…2, 1600 шагов,
21 кадр. Его поля и GIF лежат в `demo_wake`. Это грубая сетка и начальный
переходный процесс; коэффициенты этого прогона не подтверждают точность.

**Не выполнены:** аэродинамическая валидация Cl/Cd/Cm по опытам, исследование
сеточной/пространственной/размаховой сходимости, статистической сходимости
и влияния решёточного Ma, количественная проверка перехода и ламинарного
пузыря, высокоразрешённый расчёт при Re=100000. Локального сгущения нет.
Средние результаты демонстрации нельзя считать расчётной полярой.
