Это демонстрация сохранения полей и анимации 3D расчёта на грубой сетке.
Конфигурация для воспроизведения: `examples/naca0012_wake_demo.json`.

Показан срез посередине периодического размаха, а не двумерный расчёт.
Начальный переходный процесс t*=0…2 ещё содержит сильные пульсации сил.
32 ячейки на хорду не разрешают пристенный слой с доказанной точностью.
Cl/Cd/Cm в CSV и JSON здесь нельзя использовать как инженерные коэффициенты
или как подтверждение совпадения с экспериментом. Усреднение t*=1…2
сделано только для проверки функции сохранения статистики.
