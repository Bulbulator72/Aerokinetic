# Верификация и исследование численной неопределённости

## Подбор проверок под изменение

| Изменение | Минимальное независимое основание проверки |
|---|---|
| Оператор столкновений, тип данных, ускорение | Равновесие, масса/импульс, аналитическое затухание сдвиговой волны, сравнение с проверенным backend |
| Стенка и геометрия | Точное пересечение связей и контура, известное плоское/криволинейное течение, давление на замкнутый контур, разрешение тонких элементов/щелей |
| Силы и момент | Баланс обмена импульсом, нулевая нагрузка от изотропного давления, отражательная симметрия, независимый тест плеча и знака момента |
| Внешняя граница, выход | Перенос возмущения через границу, отражения и массовый баланс, изменение расстояния до границы |
| Локальное сгущение | Балансы на переходах уровней, согласование вязкости/времени, перенос волны и вихря через интерфейс, сравнение с однородной сеткой |
| SGS или начальные возмущения | Однородное равновесие без искусственного источника, модельная вязкость, независимость статистики от запуска, влияние на переход и стенку |
| История, средние и анимация | Согласованное время выборок, известная последовательность/сигнал для статистики, воспроизводимость CSV и кадров; физические поля отличаются от изображения |
| Только документация | Ссылки, единицы, статусы и соответствие текущему коду; новый физический прогон не требуется |

Не запускай всю матрицу по любому изменению текста. Для численного изменения
выполни релевантные проверки и обязательные проверки известных затронутых
инвариантов. Расширяй проверки при новом отказе или неустранённом сомнении.

## Инварианты и единицы

- Отделяй массу/импульс в периодической замкнутой задаче от баланса с
  потоками через открытые границы. Средняя плотность в открытой задаче сама
  по себе не является проверкой сохранения массы.
- Контролируй конечность полей, диапазон плотности, локальный Ma, скорость
  изменения статистики, состояние элементов и счётчики fallback стенки.
- Для zero-centered распределений учитывай вычитание фонового равновесия;
  проверяй полные нагрузки на замкнутом теле независимо от представления PDF.
- Референсная хорда относится к полной сборке. Контуры механизации остаются
  в общей системе координат; нормировка каждого по отдельности недопустима.
- Для участка с периодическим размахом Lz сила нормируется на q*c*Lz,
  момент — на q*c²*Lz. В текущем проекте +Cl вверх, +Cd вниз по потоку,
  +Cm на кабрирование. Явно проверяй точку момента и знак относительно Mz.
- Не применяй зависимую от истории выходную границу повторно только для
  вычисления диагностической силы. Сверяй время силы и состояние поля.

## Стенки и несколько элементов

Проверь ориентацию, замыкание и отсутствие пересечений контуров; сохрани
реальные щели и толщину задней кромки. Убедись, что элементы представлены
твёрдыми ячейками, а щели — жидкими, и что требуемые интерполяции имеют
соседние жидкие узлы. Укажи количество и расположение fallback-связей.
Одного числа «ячеек на хорду» недостаточно для оценки пристенного слоя.
Используй профили скорости, разрешение по нормали и подходящие масштабы,
включая y+ там, где он применим. Не объявляй разрешение достаточным по
универсальному порогу 256/512 ячеек без измерений и сходимости.

## Локальное сгущение

До реализации выбери закон изменения Δt между уровнями и выведи
ν_physical = cs_lattice²*(tau−1/2)*Δx²/Δt. Из этого вычисляй параметры
столкновений каждого уровня. Проверяй локальный решёточный Ma.

Restriction/prolongation должны сохранять нужные макромоменты и корректно
масштабировать неравновесную часть PDF. Определи субшаги, момент обмена,
призрачные слои, обработку стенок и принадлежность нагрузок на интерфейсе.
Исключи двойной подсчёт сил. Укажи измеренные ошибки обмена массой и импульсом
и сравнение с равномерной сеткой для одного физического решения.

## Пространство, время, размах и Mach

Для заявления о точности подготовь систематическую матрицу:

1. Не менее трёх разрешений, если заявляешь наблюдаемый порядок, Richardson
   или GCI. При двух разрешениях сообщай разность, не выдумывай порядок.
2. Независимое изменение размеров внешней области и расстояния до выхода.
3. Изменение периодического размаха и его разрешения. Проверяй, не навязывает
   ли область длину вихрей; используй корреляции по размаху, когда нужны
   заявления о разрешённой турбулентности.
4. Изменение решёточного U/Ma и связанного Δt при тех же физических Re,
   геометрии и условиях. Учитывай изменение tau; называй эту проверку
   совместной временной/Mach-проверкой, если эффекты нельзя разделить.
5. Для нестационарного случая сравнивай средние, RMS, спектры/частоты и
   подходящие поля. Совпадение отдельных кадров не является сходимостью.

Порядок, Richardson и GCI допустимы при обоснованном асимптотическом
поведении. Шумные, немонотонные, переходные результаты сначала требуют
оценки статистической неопределённости; формальная подстановка трёх чисел
не создаёт надёжной оценки ошибки.

Не назначай универсальное время разгона и усреднения без проверки.
Исключай начальный процесс по истории. Оцени временную корреляцию,
эффективное количество независимых выборок и, например, блоковые средние.
RMS пульсаций не является ошибкой среднего. Записывай длительность в tU/c,
частоту выборки, окно усреднения, seed и метод оценки интервала.

## Доказательства

Для каждой проверки сохрани команду, конфигурацию, идентификатор кода или
хеш исходников, версии зависимостей, CPU/GPU, ОС и сырые численные итоги.
Допуски обосновывай до просмотра ошибки. Не калибруй параметры на той же
выборке и затем не называй её независимой валидацией.

Релевантные существующие команды из корня проекта в активном окружении:

```text
python -m pytest -q
python -m aerokinetic.cli plan examples/naca0012_re30000_plan.json
```

`plan` не запускает физический расчёт и не подтверждает достаточность сетки.
Новый длительный прогон требует отдельной конфигурации и достаточного
измеренного бюджета; имена demo/preview не являются эталонными случаями.
