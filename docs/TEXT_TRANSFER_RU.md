# Передача через TXT при ошибке скачивания ZIP

Этот вариант подготовлен, поскольку на телефоне пользователя TXT открывается,
а скачивание ZIP завершается сообщением «Не удалось скачать артефакт».
Успех скачивания TXT пользователем ещё не проверен; это попытка обхода
сбоя выдачи файлов, а не исправление сервиса ChatGPT.

В `/workspace/DOWNLOAD_AEROKINETIC/AEROKINETIC_RESTORE.txt` находится обычный
текстовый BAT с полным малым комплектом `AEROKINETIC_START.zip` в base64.
Внутри тот же исследовательский выпуск 0.2.0. Код решателя не менялся.

1. На Windows сохраните **весь** TXT, включая длинный блок данных в конце.
   Если доступен только просмотр текста, скопируйте всё его содержимое в
   Блокнот. Сохраните как `AEROKINETIC_RESTORE.bat`, тип «Все файлы»,
   кодировка ANSI: весь файл состоит из ASCII. Не добавляйте расширение `.txt`.
2. Запустите BAT. Встроенный PowerShell Windows 10/11 проверит длину и SHA-256
   архива, затем восстановит его и распакует в новую папку рядом с BAT.
   Права администратора и интернет для распаковки не требуются.
3. Откройте подпапку `aerokinetic`, прочтите `0_READ_SMALL_PACKAGE_RU.txt`.
   На компьютере с интернетом выполните `1_download_ONLINE_WINDOWS.bat`;
   при необходимости подготовьте также C++ Build Tools через
   `1b_download_COMPILER_ONLINE.bat`. Затем перенесите всю папку с `downloads`
   на автономный компьютер и следуйте `START_DESKTOP_RU.md`.

Проверены обратное декодирование при CRLF/LF, совпадение архива байт в байт,
CRC и все распакованные файлы. Выполнение BAT/PowerShell на Windows и
скачивание пользователем не проверены. Частичный текст не проходит проверку
SHA-256; при такой ошибке нужно сохранить файл целиком.

Воспроизводимая подготовка:

```text
python tools/make_text_transfer.py /workspace/DOWNLOAD_AEROKINETIC/AEROKINETIC_START.zip /workspace/DOWNLOAD_AEROKINETIC/AEROKINETIC_RESTORE.txt
```

Скрипт создаёт соседний `.check.json` с хешами и статусами. Он упаковывает
существующий архив и не перестраивает решатель. Ограничения модели и
незавершённая аэродинамическая валидация остаются прежними.
