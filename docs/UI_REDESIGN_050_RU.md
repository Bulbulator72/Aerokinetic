# Интерфейс 0.5: рабочее пространство

Задача: подготовить одну расчётную точку и изучить её результаты без
поиска параметров в длинной общей форме. Основной сценарий: геометрия и
режим → сетка → расчёт → результаты. Это свободная навигация, не мастер.

Выбрана существующая Tkinter/ttk с Matplotlib, без новых зависимостей.
Для первого обновления она позволяет сохранить проверенную автономную
поставку и все действующие окна. Qt остаётся возможным последующим
решением, если появится задача, требующая его средств. Миграция ради
одного оформления сейчас не нужна.

До изменений зафиксированы критерии приёмки:

- Постоянная навигация по четырём задачам; в результатах форма освобождает
  место графикам. Формы прокручиваются, разделитель регулируется.
- Видны название и изменённость проекта, режим, источник результатов и
  состояние операции. Несохранённый ввод не теряется при смене раздела;
  перед заменой проекта/выходом доступно сохранение.
- Сохраняются генератор NACA4, несколько DAT, точка момента, все Flow/Grid/
  RunSettings/StopCriteria и скрытые поля, уровни и настройки сгущения.
- Сеткопостроитель, четыре компоненты невязок, выбор потоков, штатная
  остановка/продолжение, статистика, эксперимент и GIF доступны как прежде.
- Ошибочное число сохраняется в форме, имеет пояснение и указание поля.
  Десятичная запятая и точка поддержаны, NaN/Inf отвергаются.
- На графиках работают увеличение, панорамирование и сохранение PNG.
  Пустые состояния объясняют отсутствие данных; поля не сглаживаются.
- Реальный короткий CPU-расчёт, остановка/продолжение, старый проект и
  результат, экспорт проверяются из установленного wheel. Сохранённые
  исходные результаты при просмотре не изменяются.
- Проверяются Linux GUI 1280×720 и увеличенный шрифт/масштаб. Windows/DPI
  и пользовательская сборка EXE фиксируются отдельно, без переноса
  результатов Linux на Windows. Физическая валидация сюда не входит.

Численный код, физические ограничения, нормировки, формат checkpoint и
CLI/API не меняются. Цвета, шрифты и локальные изображения не требуют сети.
Новая поставка должна содержать wheel и обновлённый переносимый сборщик;
старые пользовательские комплекты сохраняются.
