# Проверка интерфейса AeroKinetic 0.5.0

Задача и критерии зафиксированы перед реализацией в
[UI_REDESIGN_050_RU.md](../UI_REDESIGN_050_RU.md). Сохранена Tkinter/ttk:
новых runtime-зависимостей нет. Проверяется установленный wheel, затем
перенесённая замороженная программа; исходники расчётного ядра и форматы
состояния сохранены. Итоговые машинные данные — [CHECKS.json](CHECKS.json).

Среда: Linux x86_64, CPython 3.12, Tk 9.0.4, Matplotlib 3.10.8; закреплённые
lbmpy/pystencils 1.4. Для X11 использован локальный Xorg :98 и существующие
DejaVu-шрифты, подключённые в X server. Это настройка стенда с Tk без Xft,
а не новая зависимость Windows. Полное окружение установлено из местных
wheels командой pip `--no-index`; `pip check` выполнен успешно.

Проверки и воспроизводимые команды:

- `tools/smoke_ui_050.py --output <новая папка>` — старый проект/результат,
  сохранность всех Flow/Grid/RunSettings и геометрии, числовые ошибки,
  научная запись, десятичная запятая, отмена замены черновика, Ctrl+S,
  несколько DAT, отмена/применение сетки, реальные два потока CPU,
  остановка/продолжение до 30 крупных шагов, четыре компоненты невязок,
  PNG/GIF, статистика и архив. Исходные project/history/residuals/summary
  остались побайтно прежними. [WORKFLOW_CHECK.json](WORKFLOW_CHECK.json).
- После правок защиты сохранения и компоновки проверен финальный wheel:
  запись поверх project.json расчёта отвергается, сохранение отдельной
  копии работает, параметры черновика и результата различимы, неправильный
  ввод сохраняется. [FINAL_GUI_CHECK.json](FINAL_GUI_CHECK.json),
  [сценарий](final_gui_check.py).
- `python -m pytest -q -o pythonpath= tests/test_geometry_and_units.py
  tests/test_temporal.py tests/test_convergence.py tests/test_mesh.py
  tests/test_portable_packaging.py` — 32 теста в установленном финальном
  окружении. [TESTS.xml](TESTS.xml).
- `tools/portable/build.py --app-root <стенд> --kit-root <проект>
  --wheel <wheel> --work-dir <новая папка> --linux-proof --prepared-env` —
  PyInstaller 6.16.0, перенос всей папки в путь с пробелами и кириллицей,
  проверка SHA-256, пустой кеш, отключённые Python connect/DNS, настоящий
  C++ OpenMP, равномерный и двухуровневый расчёты, побайтное совпадение
  CSV прямого расчёта и продолжения, PNG/GIF/архив, реальное главное окно,
  разделы, сеткопостроитель и невязки. [FROZEN_CHECK.json](FROZEN_CHECK.json),
  [LINUX_BUILD.json](LINUX_BUILD.json).
- Точное сравнение wheel с релизом 0.4: изменены четыре GUI-файла и номер
  версии, добавлены два файла представления; остальные 26 runtime-файлов
  прежние. Все исходники нового wheel совпали с рабочими.
  [SOURCE_COMPARISON.json](SOURCE_COMPARISON.json).

При первом запуске большого GUI-сценария стенд не получил доступный для
записи кеш pystencils. Сценарий исправлен на собственный кеш в папке
проверки и повторён целиком. Это не изменение решателя. Допуски и условия
принятия результатов не менялись после измерений.

Проверка отзывчивости выполнена во время реального запуска, продолжения и
экспорта: таймер с периодом 50 мс, заранее выбранные пределы максимума 5 с
и 95-го процентиля 1 с. Измерено около 1.08 с и 0.094 с соответственно.
Это короткий CPU-случай на стенде, не гарантия задержек большого расчёта
на пользовательской машине. Нормы невязок и численный шаг не менялись.

Ограничения проверки:

- Windows 0.5/MSVC и настоящий Windows DPI здесь не запускались. Сборщик
  выполняет проверки нового EXE дома; CHECK_PORTABLE.bat нужно выполнить
  на автономном целевом ПК. Сообщение пользователя об успешной прежней
  версии сохранено как пользовательский результат, не как новая проверка.
- В Linux проверено увеличение масштаба: числовые поля перестраиваются
  вертикально, формы прокручиваются, основные кнопки остаются доступны.
  Полная компоновка графиков при 200% и 1280×720 ограничена местом:
  Matplotlib может предупредить о тесных осях. Для графика используйте
  «Результаты» или увеличьте окно. Полная поддержка Windows DPI не заявлена.
- Запрет Python-сокетов не является системной изоляцией сетевого стека
  нативных библиотек. Новых сетевых ресурсов интерфейс не использует.
- Короткие расчёты подтверждают связность интерфейса, ядра и упаковки.
  Они не подтверждают сходимость аэродинамических коэффициентов,
  разрешение турбулентности или совпадение с продувками. Re и Mach не
  расширялись. Исследовательский статус физической точности сохраняется.
