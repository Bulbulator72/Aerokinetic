# Версия 0.2.0: окно программы и продолжение расчёта

Дата проверки: 26 октября 2026 г. Проверенная платформа: Linux x86_64,
CPython 3.12, CPU, float64. Windows/MSVC и CUDA не проверялись.

Выпуск добавляет самостоятельное окно к существующему исследовательскому
трёхмерному ядру. Оператор столкновений, обмен импульсом, Bouzidi и
внешние граничные условия не заменялись. Диапазон ядра остаётся
Re=10⁴…10⁵ и физическое M≤0.15. Это этап разработки программы,
а не подтверждение точности для научных исследований.

## Изменения

- Русское окно с генератором NACA 4, импортом отдельных контуров DAT,
  оценкой памяти, параметрами одной точки и физической хордой в метрах.
- Переносимые проекты JSON: контуры встроены в файл, точка момента
  сохраняется и задаётся в метрах относительно передней кромки.
- Графики истории Cl/Cd/Cm, просмотр сохранённых сечений скорости,
  давления и завихренности, GIF с безразмерными/физическими единицами.
- Контрольные состояния CPU: оба PDF-буфера, служебные поля,
  индексы и память экстраполяционной выходной границы. Один файл NPZ,
  без pickle; атомарная замена сохраняет предыдущий файл при ошибке записи.
- Остановка между полными шагами; продолжение исходного проекта до
  исходного конечного времени. Изменённые проект/режим/история отклоняются.
  После сбоя данные позднее контрольной точки архивируются в `recovery`.
- Встроены только реальные продувки: Cl Ohtake Re=30000 и Cl/Cd/Cm
  Ladson NASA TM-4074, таблица IX, Re=5.95 млн, M=0.15, 80-W.
  Сравнение проверяет условия, запрещает экстраполяцию и переносит момент
  в c/4. Все разности остаются предварительными (`comparison_only`).

Проверка установленного wheel:

```text
python -m pip install --no-index --find-links downloads/wheels_linux -r requirements-offline-py312.txt aerokinetic==0.2.0
python -m pip check
python tools/check_offline_runtime.py --output new_offline_run
```

Для этой проверки задавались отдельные пустые `PYSTENCILS_CONFIG`,
`PYSTENCILS_CACHE_DIR`, `MPLCONFIGDIR`. Скрипт дополнительно запрещает
Python-вызовы socket.connect/create_connection и выполняет pytest с
`-o pythonpath=`, чтобы тестировать установленный wheel. Это не измерение
всего сетевого трафика операционной системы. Сам пакет не содержит
операций загрузки данных из сети во время работы.

GUI проверен через локальный дисплей Xorg с dummy-драйвером и шрифтом
DejaVu Sans. Команда для среды с рабочим дисплеем:

```text
python tools/smoke_desktop.py --output new_desktop_check
```

## Ограничения и дальнейшая работа

Сетка равномерная. Достаточное разрешение пограничного слоя, щелей и
размаха ещё нужно обосновать. Сохранение/загрузка большого состояния
требует дополнительной RAM и места на диске; оценка Plan не является
измеренным пиком памяти. Численная ревизия контрольного формата — 1,
зависимости при загрузке должны совпадать. Совпадение битов показано на
одной платформе, не гарантируется между разными компиляторами/машинами.

Полноценное ядро для M=0.4, локальное сгущение, проверенная высоко-Re
пристенная модель и встроенный генератор механизации ещё требуют
разработки. Импорт готовых контуров механизации доступен.
Предкрылок в генератор не добавлялся.

Встроенная NASA-серия Re=5.95 млн доступна для просмотра, но её режим
не запускается текущим низко-Re ядром. Для малого Re пока оцифрован
только Cl одной серии. Примерные пределы оцифровки Ohtake не равны
погрешности продувки. Ни совпадение нескольких коэффициентов, ни
успешные тесты запуска не заменяют независимую аэродинамическую валидацию.

Порядок следующих физических этапов: выбор и верификация новой модели,
сгущение и проверка обмена между уровнями, согласованные с трубой
одноэлементные случаи, затем механизация/отрыв и исследование сходимости.
Работа по [техническому заданию](PROGRAM_REQUIREMENTS_RU.md) продолжается.
