# 0.5.2 не выпущена: результаты исследования

Характеристические условия дальней границы не прошли обязательный расчёт
NACA0012 до tU/c=12. Последний вариант остановился при6.49 и8.30 на областях
с выходом3c и6c. Успешные короткие тесты и автономная упаковка не отменяют
этот результат. [Полный отчёт](verification_farfield_20261107/REPORT_RU.md).

Основная ветка и сценарий поставки остаются на0.5.1. Новый Windows-комплект
не выдаётся. Код0.5.2, команды выбора границы и промежуточные wheel в этой
ветке сохраняются для воспроизведения исследования; это не рекомендуемая
замена работающей программы.

Практическое дополнение для основной ветки — инструмент
[capture_failure.py](../tools/capture_failure.py). Он восстанавливает
последний допустимый CPU-checkpoint, воспроизводит NumericalFailure
с исходными защитами и сохраняет сечение при самом останове в новую папку.
Исходные результаты защищены проверкой SHA-256. Полные PDF по запросу —
диагностические массивы, а не checkpoint для продолжения.

Инструмент проверен на выпущенной0.5.1 и на обоих неудачных случаях
исследовательского кандидата. [Проверка0.5.1 и команда запуска](verification_failure_capture_20261107/REPORT_RU.md).
