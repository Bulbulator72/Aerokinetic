# AeroKinetic 0.4.0: сетка, невязки и потоки CPU

Добавлены три запрошенные возможности:

1. **«Сеткопостроитель…»**: область, разрешение, размах и сгущение,
   оценка памяти, линии сетки и центры твёрдых ячеек, приближение,
   применение и сохранение проекта.
2. **«Невязки / остановка…»**: масса и три компоненты импульса,
   L2/L∞, живые графики и условия окончания. История — `residuals.csv`.
3. **Многопоточный CPU для двух уровней**: число потоков задаётся
   в параметрах сетки. Преобразования распределений дополнительно
   перенесены в скомпилированные ядра.

## Обновление без сети

Скачайте **один `UPDATE_AEROKINETIC_040.txt`**, сохраните целиком как
`UPDATE_AEROKINETIC_040.bat` рядом с `6_run_AEROKINETIC.bat` и `.venv`.
Закройте программу, запустите обновление, затем `6_run_AEROKINETIC.bat`.
В заголовке появится 0.4.0. Интернет и новые Python-пакеты не нужны.
Создаётся резервная копия; проекты и результаты сохраняются.
Поддерживаются установки 0.2.0/0.2.1/0.3.0/0.4.0.

Компилятор C++ остаётся необходимым для локальных ядер. Его установка
и ошибка Visual Studio 5003 — отдельная задача. Нативное выполнение
Windows/MSVC в среде разработки не проверено; проверки проведены на Linux CPU.

## Настройка

В сеткопостроителе нажмите «Построить / проверить», затем «Применить сетку
к проекту». Закрытие черновика не меняет проект. «К профилю» и панель
масштабирования позволяют осмотреть реальные ячейки.

Число потоков задавайте перед запуском. На i9-12900K можно начать с 4–8
и замерить время; здесь проверены 1 и 2. В сгущённом режиме явная SGS
пока не поддержана. Пример с двумя потоками:
`examples/naca0012_refined_re30000_cpu.json` — короткая проверка запуска.

В «Невязки / остановка» задайте предельное tU/c, при необходимости число
шагов и секунды. Для автоостанова по невязкам выберите второй режим,
четыре порога L2, минимальное tU/c и число успешных проверок подряд.
Нажмите «Применить условия» и сохраните проект либо начните расчёт.
Во время работы настройки заблокированы, графики обновляются.
Продолжение использует настройки сохранённого проекта.

По умолчанию останов задаётся временем. Невязки измеряют **стационарность
полей**; у нестационарного отрывного течения они могут не стремиться к нулю.
Интегральные балансные ошибки выведены отдельно и не управляют автоостановом.
Подробности — [MESH_RESIDUALS_CPU_RU.md](MESH_RESIDUALS_CPU_RU.md).

## Измеренный результат и ограничения

На сетке 32→64 ячейки/хорду полный расчётный шаг занимал 1.914 с
в 0.3.0 и 1.218 с в 0.4.0 с двумя потоками: около **1.57×**.
Это результат всех изменений. Разница между одним и двумя потоками
версии 0.4 на этом случае мала; линейное ускорение не подтверждено.
Замер исключает компиляцию и файлы; другой ПК и сетка требуют своего замера.

Рабочий диапазон сохраняется: Re=10⁴…10⁵, физическое M≤0.15.
Пороги невязок и число потоков не подтверждают аэродинамическую точность.
Сходимость профиля и полная валидация Cl/Cd/Cm ещё не установлены.
[Проверки 0.4](verification_040/REPORT_RU.md).
