# Перенос состояния между уровнями 2:1 — отчёт

Дата UTC: 27 октября 2026 г. Статус: **проверенный исследовательский модуль
переноса; локальное сгущение рабочего расчёта профиля ещё не реализовано**.

## Результат

Добавлены `aerokinetic.refinement`, воспроизводимый стенд
`aerokinetic.refinement_checks` и команда `verify-refinement`. Перенос
сохраняет плотность и импульс каждого родителя, согласует шаги dx/dt
и независимо масштабирует сдвиговую и объёмную части напряжения.
Реализованы два явных донорских halo-слоя, предиктор средних по пяти
ячейкам, обратное усреднение восьми детей и временная интерполяция
на половине крупного шага.
Независимые высшие неравновесные моды регуляризуются.

Это законченный первый этап из [дорожной карты](../ROADMAP_RU.md).
В проверочном опыте вся периодическая область меняет разрешение
в синхронизированный момент. Пространственного стыка одновременно
работающих областей в опыте нет. Производственный `solver.py`, стенки,
геометрия, нормировка сил, GUI и прежние checkpoint не изменены.

Из 52 тестов 27 относятся к новому переносу. Остальные проверяют прежние
единицы/геометрию, планирование, статистику и экспериментальные данные.
Не выполнялась вся историческая матрица ядра: производственный численный
код побайтно прежний, что проверено относительно выпущенного wheel 0.2.1.

## Постановка численного опыта

- Linux x86-64, Python 3.12.14, NumPy 2.3.5, SymPy 1.12.1,
  lbmpy 1.4, pystencils 1.4, CPU, float64, один поток.
- Трёхмерный периодический массив; контрольная сдвиговая волна зависит
  от x, однородна по y/z. Трёхмерная турбулентность не заявляется.
- Область 24×4×4 в общей безразмерной системе единиц, крупный массив
  24×4×4, мелкий 48×8×8. Неподвижного тела, стенок и выходной границы нет.
- dx/dt крупного уровня 1/1, tau_shear=0.59, tau_bulk=1;
  мелкого 0.5/0.5, tau_shear=0.68, tau_bulk=1.5.
- Кинематическая сдвиговая вязкость 0.03 в общих единицах; средняя
  скорость по x — 0.04, амплитуда поперечной скорости — 10⁻⁴.
  Решёточный Mach около 0.0693. Нет SGS, силы и случайных возмущений.
- Начальные PDF — равновесные; задаются точные средние гармоники по
  ячейкам. Аналитический закон — адвекция с экспоненциальной диффузией.
- Продолжительность 120 общих единиц времени; смена всей сетки при
  t=40 и t=80. Шаг времени мелкого уровня вдвое меньше.
- Один мелкий PDF-массив занимает 663 552 байта без буферов и служебных
  структур. Пиковая память всего процесса с JIT отдельно не измерялась.
- Атмосфера ISA, метрическая хорда, угол, Kn и аэродинамические
  коэффициенты не назначаются этой абстрактной периодической задаче.

| Вариант | Ошибка комплексной гармоники в конце | Вязкость по затуханию |
|---|---:|---:|
| Равномерная крупная | 0.6472% | 0.03011422 |
| Равномерная мелкая | 0.1385% | 0.03001737 |
| Крупная → мелкая → крупная | 0.6223% | 0.03011439 на конечном крупном участке |
| Отрицательный контроль: неверный tau на мелкой | 12.9607% | 0.01501426 вместо 0.03 |

График: [shear_wave.png](shear_wave.png). Значения относятся к проверочной
волне. Порядок около пяти характеризует только предиктор средних.
Это не порядок точности всего решателя и не GCI для Cl/Cd/Cm.

## Поставка и идентичность кода

Внутренний проверочный wheel отличен от ранее выданного стабильного
обновления. Для него использован build tag `1refinement`, версия приложения
не выпускалась заново. Файл:
`aerokinetic-0.2.1-1refinement-py3-none-any.whl`, 66 940 байт,
SHA-256 `e36795b19d7bd902a09da010129da5d9857fafa818f01b91cab1d48455ee42a3`.

[WHEEL_CHECK.json](WHEEL_CHECK.json) подтверждает совпадение всех 17 runtime
файлов с исходниками. Единственный изменённый прежний файл — CLI; добавлены
два модуля. В численной автономной проверке сначала использован тот же
снимок без build tag. После добавления тега все 17 runtime-файлов побайтно
сверены с проверенным wheel; tagged wheel локально установлен повторно.
Тег меняет метаданные сборки, а не исполняемый код.

Зависимости и lock прежние. Они установлены в чистую venv командой
`pip install --no-index --find-links ... -r requirements-offline-py312.txt`;
приложение установлено из локального wheel, `pip check` прошёл.
`check_refinement_offline.py` запретил соединения и DNS через Python socket,
проверил путь импорта в venv и использовал пустые object/joblib кеши.
Сеть на уровне ОС не отключалась; этот предел контроля явно сохранён.
Новых BAT для загрузки зависимостей не требуется.

Команда фактического основного прогона:

```text
OPENBLAS_NUM_THREADS=1 /workspace/aerokinetic_refinement_dev/clean_env/bin/python /workspace/aerokinetic/tools/check_refinement_offline.py --output /workspace/aerokinetic_refinement_dev/installed_offline
```

Хеши исходников и критериев — в `SOURCE_SHA256.json`. Методические источники
и полнота их чтения — в
[PROVENANCE.json](../../references/refinement/PROVENANCE.json).

## Что остаётся до рабочего сгущения

подшагами, учётом потоков, волной и вихрем, проходящими через стык.

Текущая проверка не даёт нового заявления о точности профиля, расширении
Re/M или исправлении автономного установщика MSVC на рабочем ПК.
