# Диагностика нестационарных Cl/Cd/Cm

Для текущего LBM каждый шаг является шагом физического времени. При отрыве
мгновенные коэффициенты могут колебаться. Выполнение заданного числа шагов,
затухание начального скачка и сходимость временных статистик — разные проверки.
Диапазон Cl=0…1 сам по себе не определяет физическую или численную причину.

Пользовательский проект с 64 ячейками на хорду, Re=30000, α=5°, c=1 м,
SGS=none, периодическим размахом 0,5c предусматривает 3200 шагов до tU/c=2
и среднее после tU/c=1. Наличие следа на кадре не подтверждает разрешение
пограничного слоя; по толщине NACA0012 около восьми ячеек. История этого
пользовательского прогона не входит в `project.json`. Уменьшение колебаний
к концу, о котором сообщил пользователь, согласуется с затухающим запуском,
но не устанавливает точность или статистическую сходимость.

## Возможности анализатора

Начиная с 0.2.1 анализ встроен во вкладку «Средние», а отчёт и архив
создаются кнопкой «Отчёт и архив для проверки». Подробнее об установке —
[в инструкции обновления](RELEASE_021_RU.md).

Модуль [temporal.py](../src/aerokinetic/temporal.py) читает сохранённые
`history.csv`, `metadata.json`, `summary.json` и вычисляет:

- Среднее, RMS пульсаций, минимум/максимум в заданном окне времени.
- Средние первой/второй половин, знаковую разность и средние по блокам.
- Накапливаемые средние и графики исходной истории.
- Приближённую автокорреляцию и эффективное число выборок.

Равномерность временной выборки, строгий рост времени и конечность данных
проверяются. Дубли, пропуски или NaN не превращаются в успешный анализ.
Начало осреднения берётся из `summary.json`; самостоятельно не подбирается.
RMS не объявляется ошибкой среднего. Блоки не предполагаются независимыми.
Короткий блок может разрезать период колебаний; размах его среднего сам
по себе не является критерием расходимости.
Оценка корреляции использует начальные положительные монотонные пары
выборочной автокорреляции и требует стационарности/длинной записи; она
не является доказательством этих предпосылок. Доверительный интервал
не выдаётся. Автоматического статуса «сошлось» нет, поскольку согласованный
допуск и достаточные независимые выборки не установлены.

Инструмент не меняет решатель, сетку, SGS или входные файлы. Он создаёт
новую подпапку с отчётом, графиком и `FOR_REVIEW.zip`. Последний содержит
копии четырёх небольших файлов результата, последнего кадра (если есть)
и отчёта с SHA-256. Контрольные состояния и остальные кадры не включаются.

## Автономный запуск в установленной версии 0.2

Пользователь может сохранить
`/workspace/DOWNLOAD_AEROKINETIC/ANALYZE_RESULTS.txt` как
`ANALYZE_RESULTS.bat` в папку программы рядом с `.venv`, затем запустить.
В диалоге выбирается папка конкретного результата с `history.csv`.
Встроенный текстовый перенос проверяет SHA-256 и использует существующий
Python, NumPy, Matplotlib и Tk. Установка пакетов и интернет не требуются.
Сам BAT не запускался на Windows в этой рабочей среде.

Для разработчика из исходников:

```text
python -m aerokinetic.temporal path/to/run
python -m pytest tests/test_temporal.py -q
python tools/make_temporal_launcher.py
```

Файл модуля также запускается напрямую в старом автономном окружении:

```text
python src/aerokinetic/temporal.py path/to/run --no-open
```

Выполнение на аналитическом синусоидальном сигнале Cl=0,5+0,5 sin(2πt),
линейном тренде, коррелированном AR(1) и неизменность исходных данных
проверяются отдельно. Это тесты статистики, не искусственные продувки.

Успешный отчёт не заменяет исследования сетки, области, размаха,
временного шага/решёточного Маха и условий экспериментального эталона.
При одинаковом среднем у двух сеток всё равно требуется оценить остальные
источники неопределённости. Следующий этап повышения разрешения — локальное
сгущение с проверкой обмена между уровнями, а не графическая интерполяция.
