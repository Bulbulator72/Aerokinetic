# NACA0012: первичные продувки и сравнение AeroKinetic 0.5.0

6 ноября 2026 г. Статус: **предварительное сопоставление; физическая точность не подтверждена**.

Подготовлены данные Cl/Cd/Cm: Ohtake 2007, Re=30000 (оцифровка графиков), и NASA Ladson
TM-4074, Re=5.95 млн, M=0.15, трип 80-W (исходная числовая таблица IX).
Для низкого Re выполнены два новых расчёта установленным wheel 0.5.0. При высоком Re
расчёт не запускался: ограничения выпущенного ядра сохранены. Механизации в этой серии нет.

Условия расчёта: NACA0012 с конечной толщиной задней кромки, Re=30000, α=4°,
c=0.15 м, точка момента c/4; CPU, 2 потока; D3Q27 cumulant, SGS=none,
U_lattice=0.04, периодический размах 0.5c. Общая цель tU/c=6, осреднение после 3.
Cl вверх, Cd по потоку, Cm на кабрирование; нормировка на c×Lz и c²×Lz.

| Коэффициент | Опыт, интерполяция при 4° | 32 яч./c | 64 яч./c |
|---|---:|---:|---:|
| Cl | ≈0.308739 | 0.202859 | 0.198665 |
| Cd | ≈0.044509 | 0.074446 | 0.054327 |
| Cm(c/4) | ≈-0.020533 | 0.016998 | 0.019688 |

Результаты и исходные истории: [comparison/](comparison/). Средние рассчитаны по
фиксированному окну, параметры не подбирались по эксперименту. RMS пульсаций не является
ошибкой среднего. Дрейф и зависимость отсчётов не позволяют объявить средние сошедшимися.
Переход 32→64 меняет также dt и численное затухание объёмной моды при фиксированном
параметре релаксации: это совместная чувствительность к дискретизации, а не чистая
пространственная сходимость. Проверки области, размаха и решёточного Mach не выполнены.
Геометрия модели трубы, переход, остаточная турбулентность и торцевые условия совпадают
не полностью либо недостаточно известны. Причины расхождения коэффициентов ещё не выделены.

Сетка 64 штатно остановилась при t*=5.435 по лимиту 1800 секунд одного запуска.
Затем продолжена из checkpoint до исходных 9600 шагов, t*=6. Проверены неизменность
случая, настроек и префикса истории. Начальный отчёт сохранён отдельно в continuation64/.

Проверки согласованности данных — [comparison/CHECKS.json](comparison/CHECKS.json).
В них независимо пересчитаны средние/RMS/разности из CSV, проверены количества маркеров,
порядок углов, отсутствие экстраполяции, SHA-256, воспроизводимость оцифровки и запрет Re=6e6.
Это не проверки физической точности. [RUNTIME_IDENTITY.json](RUNTIME_IDENTITY.json)
подтверждает совпадение 33 файлов исходного ядра, установленного пакета и исходного wheel.
Ядро и GUI в этой работе не изменялись. Необходимости пересобирать EXE из-за этих отчётов нет.

Источники и условия: [sources/PROVENANCE.json](sources/PROVENANCE.json).
Новые Cd/Cm и визуальное выделение маркеров: [experimental/](experimental/).
Исходные статьи сохранены в references/, авторство и условия источников сохраняются.
Параметры до расчётов: [PLAN.json](PLAN.json); фактические частоты релаксации:
[METHOD_AUDIT.json](METHOD_AUDIT.json). Обнаруженное при аудите изменение объёмного затухания
не использовалось для изменения настроек; оно раскрыто как ограничение анализа.

Воспроизведение из корня проекта с установленным 0.5.0:

```text
python tools/digitize_ohtake_coefficients.py references/ohtake2007.pdf NEW_WORK/digitization_recheck
python tools/run_naca0012_comparison.py --output NEW_WORK/runs
python tools/resume_naca0012_comparison.py --runs NEW_WORK/runs
python tools/compare_naca0012_20261106.py --work NEW_WORK --output NEW_WORK/comparison_final
```

Команда продолжения нужна только после остановки 64 по wall_time_limit.
Анализатор читает проверенные Cd/Cm из references/. Повторная оцифровка в новую папку
проверяет их воспроизводимость без изменения эталона. PyMuPDF нужен для подготовки
источников, а не для запуска решателя. Полные checkpoint/кадры текущих прогонов
сохранены в /workspace/aerokinetic_validation_20261106/runs/ и не дублируются в этом отчёте.
