# Первая серия расчётов в программе Claude

**План отложен по новому указанию пользователя: пока сравниваться только
с продувками.** Повторный SA-прогон 12° и следующие прогоны Claude сейчас
не запрашиваются. Ниже сохранена история исходной постановки.

Полученная выгрузка 10°/12° и её
[разбор](../benchmarks/claude_sa_2026-10-26/REPORT_RU.md) сохранены.
В первичном PDF уточнены Re=5.95 млн, обозначение 80-W и Cm выбранной серии.

Выбран **NACA 0012 без механизации**, встроенный генератор, с замкнутой
задней кромкой. Дата выбора: 26 октября 2026 г. Сначала собираем
воспроизводимые результаты этой программы; валидация нового кинетического
решателя этим ещё не выполняется.

## Настройки окна

| Поле | Значение |
|---|---|
| Профиль NACA | `0012` |
| Механизация | нет; предкрылок также выключен |
| Метод | RANS (Спаларт–Аллмарас) |
| Re | `6e6` |
| Число Маха | `0.15` |
| Первый угол | `10.12` градуса |
| α от / α до | оба `10.12` |
| Шаг α | `1` (при одинаковых границах будет одна точка) |
| Итераций на угол RANS | `400` |
| Точка момента | штатная: x/c=0.25, y/c=0 |

Поля Ncrit и положения перехода не используются веткой RANS: модель
полностью турбулентная от носка. Поле «Сетка» в окне относится к Эйлеру;
сетка RANS строится gmsh автоматически. Геометрию между точками не менять.

После первого обмена результатами: α = **15.26, 16.30, 17.13, 18.02°**,
по одной точке за запуск. Эти углы взяты из одной экспериментальной серии,
включающей резкое падение подъёмной силы. Дополнительные углы, обратный
проход и сгущение сетки назначаются после разбора исходной серии.

В программе координаты встроенного профиля нормированы на единичную хорду;
метровая хорда в этом окне не задаётся. Для физически подобного случая
ISA на уровне моря при выбранных Re/M: U∞=51.0441 м/с, c=1.71703 м
(ν=1.4607346723e-5 м²/с, a=340.293988 м/с). Это масштаб для последующего
кинетического расчёта, а не размер модели в исходной продувке.

## Что прислать

1. «Сохранить таблицу (CSV)»: Cl, Cd, Cm и флаг «надёжно».
2. График Cp для соответствующего угла: штатный PNG.
3. Текст вкладки примечаний/сообщений: число ячеек, сошлось ли решение,
   предупреждения. Если сохранился журнал итераций — приложить его.
4. Ориентировочное время расчёта и снимок настроек либо их текст.

Неудачно сошедшийся режим тоже полезен: сохранить его и исходные настройки.
Флаг «надёжно» в CSV обозначает критерий сходимости данного решателя;
сам по себе он не доказывает точность сил. Итерации здесь относятся к
поиску стационарного решения и не являются историей физического времени.
При развитом отрыве стационарный RANS может не установиться.

Запрашивается Cp, который эта версия действительно выдаёт. Полноценное
поле скорости RANS через `core.run_rans` в GUI не передаётся (`field_ctx`
не заполнен); обязательного экспорта такого поля в первом запросе нет.

## Источники и границы сравнения

Эксперимент: Ladson, NASA TM-4074 (1988), Re=6 млн, M=0.15,
фиксированный переход. Берём отдельно серию **80 grit**:

| α, ° | Cl опыта | Cd опыта |
|---|---:|---:|
| 10.12 | 1.0707 | 0.01201 |
| 15.26 | 1.5129 | 0.01900 |
| 16.30 | 1.5739 | 0.02218 |
| 17.13 | 1.6116 | 0.02560 |
| 18.02 | 0.9967 | 0.18785 |

Значения — из сохранённого оригинального
[CLCD_Ladson_expdata.dat](../references/nasa_tmr/CLCD_Ladson_expdata.dat),
SHA-256 и URL в [PROVENANCE.json](../references/nasa_tmr/PROVENANCE.json).
Полный отчёт: https://ntrs.nasa.gov/citations/19880019495.
Cm из этого отчёта для выбранной серии ещё не извлечён.

Условия трубы, трипы около 5% хорды и полностью турбулентный от носка
RANS не совпадают полностью. Особенности исходной геометрии опыта,
стеночные поправки и неопределённости требуют отдельной проверки.
Сравнение данной серии предварительное, жёсткий процентный допуск
физической точности по нему пока не назначается. Cp этой серии можно
сопоставлять между программами; сохранённые Cp Gregory и Ladson с иными
Re/M не подставлять сюда в качестве совпадающих экспериментальных условий.

Отдельная численная проверка: NASA TMR использует специальный замкнутый
и масштабированный NACA0012, отличающийся от встроенной формулы программы.
Для строгой сверки с TMR потребуется импорт именно его контура и проверка
сходимости. Наборы: https://tmbwg.github.io/turbmodels/naca0012_val.html.
