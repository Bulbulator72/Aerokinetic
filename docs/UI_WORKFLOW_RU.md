# Навык разработки интерфейса AeroKinetic

Создан 28 октября 2026 г. по запросу пользователя. Навык
[`aerokinetic-ui`](../.agents/skills/aerokinetic-ui/SKILL.md) подключён через
[AGENTS.md](../AGENTS.md) и применяется при работе над интерфейсом проекта.
Он дополняет существующий `cfd-lbm` для научных данных и автономной поставки.

## Что зафиксировано

- Пользователь разрешил самостоятельно улучшать интерфейс и выбирать
  оболочку. Tkinter — реализация версии 0.4.0, не обязательное условие.
- При выборе технологии оцениваются панели/графики, масштабирование Windows,
  фоновая работа, совместимость проектов и установка без интернета.
- Основной сценарий: проект/геометрия, сетка, расчёт, результаты. Обязательны
  сеткопостроитель, история четырёх невязок и сохранение условий окончания.
- Научные данные, нормировки, время, разрешение сетки и измерения
  отображаются явно. Интерполяция картинки не считается улучшением сетки.
- Долгие операции не блокируют интерфейс. Запуск/остановка и продолжение
  следуют реальным возможностям ядра; результаты прежних расчётов сохраняются.
- Проверяются компоновка, клавиатура, состояния ошибок, соответствие
  данных/экспорта, реальный запуск и установленная автономная поставка.

Для применения навыка пользователю ничего устанавливать не требуется.
Figma/Product Design могут помочь с макетами, но не являются зависимостями
готовой программы. Этот набор инструкций не устанавливает GUI-фреймворк.

## Состояние при создании навыка, 28 октября

Создание навыка не меняет работающую оболочку и не переносит программу
на Qt или веб-технологии. Выбор и реализация фиксируются отдельно с
проверками. Тогда версия программы оставалась 0.4.0; расчётное ядро, проекты,
численные результаты и ранее выданное обновление не изменены.

Проверки самого навыка сохранены в
[verification_ui_skill/CHECKS.json](verification_ui_skill/CHECKS.json).
Они подтверждают подключение инструкций и структуру поставки, не работу
будущего интерфейса на Windows.

29 октября выполнено обновление рабочего окна до 0.5.0. Решение и критерии:
[UI_REDESIGN_050_RU.md](UI_REDESIGN_050_RU.md), инструкция:
[RELEASE_050_RU.md](RELEASE_050_RU.md). Историческая проверка навыка не
подменяет отдельные проверки нового интерфейса.
