# Повторный 5003: собрать актуальный журнал

28 октября 2026 г. пользователь снова получил `INSTALL_EXIT_CODE=5003`.
На последнем фото нет подробного исключения. На прежнем фото был
`InvalidCertificate` при проверке локального `vs_installer.opc`; это
не доказывает, что последняя попытка завершилась по той же причине.

Microsoft описывает 5003 как сбой bootstrapper при получении установщика.
Код относится к этапу установщика и сам по себе не доказывает отсутствие
пакетов C++ в layout. Текущий BAT 2 уже использует `--noWeb` и локальный
`ChannelManifest.json`. Эти параметры сохранены; повторная попытка
с теми же входами без новых журналов не объявляется исправлением.

## Получить один отчёт без интернета

1. Скачать `COLLECT_COMPILER_DIAGNOSTICS.txt` из выданной в чате ссылки.
2. Сохранить как **`COLLECT_COMPILER_DIAGNOSTICS.bat`** в существующей
   папке AeroKinetic рядом с `6_run_AEROKINETIC.bat` и `.venv`.
3. Запустить на проблемном рабочем ПК под той же учётной записью, что BAT 2.
   Для совпадения контекста можно также выбрать «Запуск от имени администратора».
   Не требуется заново устанавливать Python или запускать компилятор.
4. Прислать созданный **`COMPILER_DIAGNOSTICS_<дата>_<код>.txt`** из этой папки.
   Каждый запуск создаёт новое имя и сохраняет старые отчёты.

Если новый BAT нельзя перенести, достаточно прислать последний
`dd_bootstrapper*.log` из самой новой подпапки
`downloads\compiler_install_details`. Этот журнал уже скопирован BAT 2.

Сборщик читает последние журналы из `%TEMP%` и до трёх последних папок
скопированных журналов, сводки загрузки/установки, размеры и SHA-256 ключевых
файлов layout. Он также читает сведения о Windows и публичных сертификатах
Microsoft из Root/CA/Disallowed в LocalMachine и CurrentUser. Длинные
журналы явно усекаются до начала и конца. Совпадающие копии не дублируются.

Изменений установок, сертификатов, политики и проекта нет. Записываются
новый отчёт и временный распакованный Python-скрипт, который затем удаляется.
Используются существующий `.venv` Python, его стандартная библиотека
и Windows PowerShell. Проверка цепочки/отзыва сертификатов не выполняется;
само наличие сертификата не подтверждает действительность подписи.
Подключения к сети и автоматическая отправка отчёта не предусмотрены.

## Проверки и границы

Проверены перенос исходника через TXT (CRLF/LF), SHA-256, выполнение сборщика
на Linux с тестовыми Unicode/UTF-16 журналами, сохранность входных файлов,
работа при отсутствии/большом размере журналов и запрет сетевых соединений.
Windows BAT, PowerShell-инвентаризация и установка MSVC здесь **не выполнены**.
Отчёт проверок — [verification_compiler_diagnostic/CHECKS.json](verification_compiler_diagnostic/CHECKS.json).
Это средство диагностики, а не подтверждённое исправление 5003.
Численное ядро, зависимости и версия AeroKinetic 0.4.0 не менялись.
