# Исправление подготовки компилятора

Пользователь сообщил: `1b_download_COMPILER_ONLINE.bat` остаётся открытым,
загрузка не видна. В предыдущей версии до первого `echo` выполнялся
`Invoke-WebRequest` с отключённым прогрессом. Отсутствовали тайм-аут,
`-UseBasicParsing` и постоянный журнал. Это объясняет отсутствие индикации,
но не доказывает конкретную сетевую причину на пользовательском ПК.

В новой версии:

- Начало и этапы видны сразу; основной загрузчик — штатный `curl.exe`
  с прогрессом, тайм-аутом соединения 20 с и общим лимитом 180 с.
- При отсутствии/ошибке curl используется Windows PowerShell с TLS 1.2,
  `-UseBasicParsing`, прогрессом и `-TimeoutSec 120`. Добавлен
  `-NonInteractive`, чтобы неожиданный запрос не оставлял скрипт в ожидании.
- Частичная загрузка имеет отдельное имя `vs_BuildTools.part.exe`; Microsoft Authenticode
  проверяется перед запуском, SHA-256 записывается в журнал.
- Комплект VCTools с рекомендованными компонентами скачивается через
  `--layout`, `--wait`; прогресс Microsoft остаётся видимым. Повторный запуск
  использует ту же папку и позволяет дополнить прерванный layout.
- Успех требует нулевого результата отдельного `--verify`; наличие одного
  маленького bootstrapper не считается автономным комплектом.
- `downloads/compiler_download.log` содержит этапы, ошибки PowerShell и
  коды завершения. При ошибках layout копируются последние журналы Microsoft
  `dd_bootstrapper*`, `dd_setup*`, `dd_vs_*` из TEMP в downloads.

Microsoft рекомендует путь layout короче 80 символов. Перед запуском
переместите **всю папку программы**, например, в `C:\AK`. Скрипт проверяет
длину пути. Запускайте BAT от имени администратора; скачивание полного
комплекта занимает несколько гигабайт. Другие BAT менять не требуется:
расположение `downloads/vs_buildtools` сохранено.

Для передачи пользователю файл сохранён как
`/workspace/DOWNLOAD_AEROKINETIC/1b_download_COMPILER_ONLINE_FIXED.txt`.
Нужно сохранить **полный** текст в папке программы как
`1b_download_COMPILER_ONLINE.bat`, заменив прежний файл. В Блокноте выбрать
тип «Все файлы», кодировку ANSI. Код состоит из ASCII; зависимости и уже
подготовленные файлы в downloads сохраняются.

## Основания и границы проверки

Официальные инструкции Microsoft:

- <https://learn.microsoft.com/en-us/visualstudio/install/create-an-offline-installation-of-visual-studio?view=vs-2022>
- <https://learn.microsoft.com/en-us/visualstudio/install/use-command-line-parameters-to-install-visual-studio?view=vs-2022>

Официальный bootstrapper по ссылке
<https://aka.ms/vs/17/release/vs_BuildTools.exe> скачан из рабочей среды:
HTTP 200, 4 474 120 байт. Это проверка доступности из этой среды, а не
свидетельство доступа с пользовательского ПК. Выполнение BAT, проверка
Authenticode, создание/проверка layout на Windows имеют статус `not_run`.
Код решателя и wheel не менялись; повторный CFD-прогон не требуется.
