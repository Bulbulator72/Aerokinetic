# Текущий комплект 0.5.1

Для подготовки новой Windows-программы скачать один файл:
[BUILD_AEROKINETIC_UI_051.txt](BUILD_AEROKINETIC_UI_051.txt).
Сохранить целиком как `BUILD_AEROKINETIC_UI_051.bat` рядом с существующей
домашней `.venv` и `6_run_AEROKINETIC.bat`, затем запустить дома с интернетом
и рабочим C++-компилятором. Рядом находится `.check.json` с хешами транспорта.

Сценарий создаёт отдельную среду и новую папку EXE с копией compiler/SDK.
Прежняя программа и `.venv` сохраняются. На рабочий ПК переносится вся
папка из `PORTABLE_READY_TO_COPY.txt`, затем запускается `CHECK_PORTABLE.bat`
с отключённой сетью. Этот TXT — сборочный комплект, а не готовый Windows EXE.

`aerokinetic-0.5.1-py3-none-any.whl` — библиотека с исправлениями и CLI/API
продления расчёта. Она не является самостоятельной Windows-программой.
Проверены installed wheel и упакованная программа на Linux CPU; новый
Windows/MSVC-прогон и проверка целевого офлайн-ПК здесь не выполнены.
Кнопки продления завершённого расчёта в GUI пока нет.

Файлы с **050** сохранены как история прежней поставки.
`TEST_NACA0012_FLAP20_RE10000.json` — прежний проект проверки механизации
при низком Re. Поддержка Re около 6 млн ещё не реализована.
