# Проектный навык CFD/LBM

Навык `cfd-lbm` создан 26 октября 2026 г. Он задаёт правила разработки и
проверки библиотеки aerokinetic. Основной файл:
[SKILL.md](.agents/skills/cfd-lbm/SKILL.md).

В навык входят:

- обязательная проверка физической постановки, единиц, Re/Ma/Kn и ресурсов;
- независимая верификация кода и исследования сходимости;
- количественная сверка с измерениями Cl/Cd/Cm и сохранение происхождения данных;
- установка из локальных пакетов в чистой среде без сети;
- [шаблон отчёта](.agents/skills/cfd-lbm/templates/report.md) со статусами
  выполненных, не выполненных и неоднозначных проверок.

## Подключение в этой рабочей папке

[AGENTS.md](AGENTS.md) указывает применять навык к численной работе,
экспериментальному эталону и автономной поставке. В текущей рабочей среде
добавлен также указатель из `/workspace/AGENTS.md` на правила проекта.

## Перенос в вашу копию проекта

1. Распакуйте `aerokinetic_cfd_lbm_skill.zip` рядом с существующей папкой
   `aerokinetic`, объединив одноимённые папки. Архив содержит инструкции,
   справочные протоколы, шаблон отчёта и обновлённый README.
2. Сохраните структуру `aerokinetic/.agents/skills/cfd-lbm/`; папка `.agents`
   может отображаться как скрытая. Runtime-библиотека от этой папки не зависит.
3. Если у вас уже есть собственный `AGENTS.md`, сохраните его правила и
   добавьте указание прочитать `.agents/skills/cfd-lbm/SKILL.md` для задач CFD/LBM.
4. Откройте именно эту папку проекта в помощнике, поддерживающем AGENTS/skills.
   Для явного применения можно написать: «Применяй проектный навык CFD/LBM
   из .agents/skills/cfd-lbm/SKILL.md к следующей задаче».

Команда pip/npm, доступ к сети и установка Scite/Firecrawl для этого навыка
не требуются. В других клиентах, не читающих AGENTS/skills, передайте
помощнику файл SKILL.md и нужные материалы по ссылкам явно. Это проектные
инструкции; они не означают глобальную регистрацию расширения в ChatGPT.

## Проверка создания навыка

Проверены YAML-заголовок, имя и описание, структура Markdown, наличие
связанных протоколов и шаблона, существование внутренних ссылок и маршрут
AGENTS → SKILL.md. Численные исходники сверены с ранее проверенным wheel:
изменений решателя нет. Существующие результаты тестов и статус научной
валидации не пересматривались. Архив проверяется на целостность; включённый
SHA256SUMS.txt содержит контрольные суммы его файлов.
